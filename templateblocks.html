import pandas as pd
import statsmodels.formula.api as smf

df_RBY_9d8 = pd.DataFrame(
    {
        "R9d8": [
            30, 35, 40, 45, 50,
            55, 60, 65, 70, 75
        ],
        "B9d8": [
            60, 55, 62, 58, 61,
            57, 63, 59, 64, 60
        ]
    }
)

df_RBY_9d8["purple_9d8"] = (
    df_RBY_9d8["R9d8"]
    +
    df_RBY_9d8["B9d8"]
)

df_RBY_9d8["orange_9d8"] = (
    df_RBY_9d8["R9d8"]
    +
    40
)

print(df_RBY_9d8)

Conditional means

NoteIn The Effect

  • conditional mean https://theeffectbook.net/ch-DescribingRelationships.html#conditional-means

  • average https://theeffectbook.net/ch-CausalitywithLessModeling.html#wide-open-spaces

This section illustrates multiple explicit block types inside a single section.

A conditional mean is an average computed within a subset of observations.

conditional_means = (
    df_RBY_9d8
    .groupby("purple_9d8")
    ["orange_9d8"]
    .mean()
    .reset_index()
)

print(
    conditional_means
)
   purple_9d8  orange_9d8
0          90        72.5
1         102        80.0
2         103        85.0
3         111        90.0
4         112        95.0
5         123       100.0
6         124       105.0
7         134       110.0
8         135       115.0

Compute the conditional mean of orange_9d8 for one observed value of purple_9d8.

Compare the regression line and the conditional means.

How are they similar?

How are they different?

Conditional means and fitted values are not the same object.

Possible classroom prompt:

“Could two datasets have the same regression line but different conditional means?”

Students frequently confuse:

  • observed values
  • fitted values
  • conditional means

A short pause here is usually useful.

Centering the predictor

NoteIn The Effect

  • intercept https://theeffectbook.net/ch-FixedEffects.html#regression-estimators

  • covariates https://theeffectbook.net/ch-DifferenceinDifference.html#picking-an-untreated-group-with-matching

This section demonstrates a non-core enrichment topic.

Centering changes the interpretation of the intercept.

purple_mean = (
    df_RBY_9d8["purple_9d8"]
    .mean()
)

df_RBY_9d8["purple_9d8_centered"] = (
    df_RBY_9d8["purple_9d8"]
    -
    purple_mean
)

print(
    df_RBY_9d8[
        [
            "purple_9d8",
            "purple_9d8_centered"
        ]
    ]
)
   purple_9d8  purple_9d8_centered
0          90                -22.4
1          90                -22.4
2         102                -10.4
3         103                 -9.4
4         111                 -1.4
5         112                 -0.4
6         123                 10.6
7         124                 11.6
8         134                 21.6
9         135                 22.6

Draw the regression line before and after centering.

Emphasize that the fitted line itself has not changed.

Students often believe centering changes predictions.

Emphasize that it only changes parameter interpretation.
